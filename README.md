نظام رقمي متكامل مبني باستخدام **Laravel 12.x** و **PHP 8.3+** و **MySQL 8.0+** مع واجهة تفاعلية بـ **Alpine.js** وتصميم حاد بالأبيض والأسود (**Sharp Monochrome Zero-Radius**).

تم تطوير المنظومة لتحويل النماذج الورقية الرسمية الخاصة ببرنامج **حقيبة الابتكار والتعبير لليافعين (UNICEF Adolescent Kit for Expression and Innovation)** إلى منظومة رقمية تفاعلية تدعم المتابعة الميدانية والتقييم (M&E).

## ⚡ أبرز مميزات النظام

### 1. لوحة تحكم إدارية مركزية (Admin Control Panel - M&E)
- **مؤشرات قيادة وطنية**: إجمالي الجلسات، اليافعين، الذكور، الإناث، نسب التمدرس، ذوو الإعاقة والأمراض المزمنة.
- **إدارة كاملة للميسرين داخل اللوحة**: إدخال وتعديل وحذف الميسرين والمساعدين مباشرة في لوحة التحكم دون الحاجة لصفحات خارجية منفصلة.
- **صندوق الاعتماد والمصادقة**: مراجعة تقارير النشاط الميدانية المحالة واعتمادها رسمياً بنقرة واحدة.

### 2. بوابة الإدخال الميداني للميسرين (Field Entry Portal)
- **إنشاء وتعديل الجلسات**: ربط ذكي بين المؤسسة والولاية والبلدية مع إمكانية التعديل الشامل لكافة بيانات الجلسة.
- **طاقم الميسرين والمساعدين الستة**: تحويل المساعدين من 1 إلى 6 إلى **قوائم منسدلة (Dropdowns)** معطَّل فيها الميسران الرئيسيان آلياً لمنع ازدواجية الأدوار.
- **مسار الانتقال الميداني**: إدخال حر ومرن لخانتي «من بلدية ... إلى بلدية ...» طبقاً للنموذج الرسمي.

### 3. كشف حضور اليافعين (70 مقعداً مع علاقات حقول ذكية)
- **حساب العمر والفئة العمرية آلياً**: بمجرد اختيار تاريخ ميلاد اليافع، يحسب النظام سنه وفئته العمرية من الفئات الـ 9 المعتمدة لحظياً قبل الإرسال.
- **علاقات حقول ذكية**:
  - التمدرس $\to$ ضبط المستوى الدراسي تلقائياً.
  - المرض المزمن $\to$ ظهور حقل تفاصيل المرض.
  - ذوو الإعاقة $\to$ تصنيف نوع الإعاقة (حركية، بصرية، صم بكم، مخصصة).
- **إمكانية التعديل والحذف الفوري**: زر `[ ✏️ تعديل ]` و `[ 🗑️ حذف ]` لكل يافع مع إعادة احتساب الإحصائيات فوراً.

### 4. المحرك الإحصائي التلقائي (`ReportAggregationService`)
- حساب فوري لـ 9 فئات عمرية: `[10-11[`, `[11-12[`, `[12-13[`, `[13-14[`, `[14-15[`, `[15-16[`, `[16-17[`, `[17-18[`, `[18-19]`.
- تجميع إحصائيات التمدرس، الجنس، ونسب الإعاقة والأمراض دون أي تدخل يدوي من الميسر.

### 5. التوثيق الإعلامي الإلزامي (Media Checklist)
- رفع ومعاينة الصور الأربع الإلزامية ومقطع الفيديو:
  1. الباب الخارجي للمؤسسة.
  2. طاقم الميسرين.
  3. صورة جماعية لليافعين والهيئة والميسرين.
  4. صورة لجميع اليافعين أثناء النشاط.
  5. فيديو النشاط (حتى 100 ميغابايت).
- معاينة مصغرة مباشرة (Thumbnail Preview) داخل الاستمارة وزر للحذف والاستبدال.

### 6. الطباعة والمطابقة الرسمية 100% (Official Print Engine)
- طباعة كشف الحضور الرسمي وتقرير النشاط متضمناً **بطاقة إشهاد الهيئة المستقبلة الرسمية** وخانات الختم والتوقيع، مطابقة تماماً للملفات الأصلية.

## 🎨 الهوية البصرية (Sharp Monochrome Design System)
- **Zero Radius**: حواف حادة بزوايا 90 درجة (`border-radius: 0px !important`).
- **أبيض وأسود فقط**: تباين عالي الجودة للقراءة السلسة تحت أشعة الشمس في الميدان وسهولة الطباعة.
- **Solid Retro Shadows**: ظلال صلبة بارزة للأزرار والجداول تعكس الرصانة والجدية الإدارية.
- **دعم اللغة العربية الكامل (RTL)** مع خط Cairo عالي الدقة.

## 🛠️ متطلبات التثبيت والتشغيل المحلي

### المتطلبات الأساسية:
- **PHP 8.3+** (مع إضافات: `pdo_mysql`, `pdo_sqlite`, `fileinfo`, `mbstring`, `openssl`, `curl`).
- **Composer 2.x**.
- **Node.js 20+** & npm.
- **MySQL 8.0+** (أو SQLite للتطوير السريع).

### خطوات التثبيت:

```bash
# 1. استنساخ المستودع
git clone https://github.com/saadmooh/adolescent-kit-system.git
cd adolescent-kit-system

# 2. تثبيت مكتبات PHP
composer install

# 3. إعداد ملف البيئة
cp .env.example .env
php artisan key:generate

# 4. تجهيز مجلد التخزين العام للميديا
php artisan storage:link

# 5. ترحيل قاعدة البيانات مع البيانات التجريبية
php artisan migrate --seed

# 6. تثبيت وبناء أصول الواجهة
npm install
npm run build

# 7. تشغيل خادم التطوير
php artisan serve
```
